# 公司系統欄位

來源：公司系統的出差申請單、旅費報支申請畫面，以及 app 後台的公司主檔。

## 出差申請單（用來核對，不用填）

| 欄位 | 用途 |
|------|------|
| 預計出差期間 | 核對住宿晚數、單據日期是否在範圍內 |
| 出差地點（洲別／國家／城市） | 檔名、判斷幣別 |
| 行程安排 | 哪幾天飛行、哪幾天工作 |
| 台北接送機 | 有填就要有接送的憑證，或確認由公司安排（不用報） |
| 班機／交通方式 | 去回程班次、艙等、時間 → 對登機證 |
| 旅費預支（需求日期／幣別／金額／匯率／折合台幣） | 有預支 → 報支表加「預支歸還」一列 |
| 機票付款方式 | 「自行刷卡」→ 報支項目用「機票(自行刷卡)」 |
| 人資作業：國際段機票／內陸段機票／改票費／簽證費／護照費／住宿 | 機票金額以這裡為準（例：同仁自購的金額） |

## 旅費報支申請（要填的七欄）

| 欄位 | 型態 | 內容 |
|------|------|------|
| 項目 | 下拉 | 見下方清單 |
| 幣別 | 下拉 | 見下方表格，填選單名稱（例：台幣、歐元） |
| 金額 | 數字 | 有信用卡明細填台幣（含手續費），沒有填原幣 |
| 憑證數 | 數字 | 算法見 rules.md |
| 附件 | 上傳檔案 | 系統一列可附多個檔；整包時一列一個 PDF（`上傳/` 裡對應的檔） |
| Remark | 文字 | 金額組成 |
| 費用歸屬 | 選取 | 本人提供，見下 |

系統另外自動顯示「匯率」：台幣為 1；外幣列顯示「公司匯率×1.025」（例：36.194X1.025、31.6X1.025）；預支歸還列只顯示公司匯率，不乘 1.025。都不用填。

下拉選單的內容以 app 後台的公司主檔為準：`app/managed-config.ts`（版本 `company-2026-08-v1`）。主檔改版時，這裡跟著更新。

### 項目（`DEFAULT_CLAIM_TYPES`）

1. 機票(自行刷卡)
2. 住宿
3. 車資
4. 落地簽證費
5. 預支歸還
6. 餐飲
7. 交際費／伴手禮
8. 行李託運費
9. 疫苗／檢測費用
10. 採買樣衣
11. 無報支費用
12. 電信網路費
13. 簽證費用

公司系統只有這 13 項。**「國外交易手續費」不是報支項目**：手續費併進它所屬的那一筆（見 rules.md）。
app 主檔目前還留著第 14 項「國外交易手續費」，那是 app 內部把手續費單獨記一筆的舊流程在用，整包時不要選它。

### 費用歸屬

app 主檔裡**沒有**費用歸屬的選項清單：它是自由輸入的文字欄位（`db/schema.ts` 的 `cost_center`，預設值 `S2_GP1 100%`）。

格式是「歸屬名稱 ＋ 百分比」，可分攤給多個歸屬。每趟出差可能不同，一律請本人提供，不沿用預設值。看過的值：`S2_GP1 100%`、`S2_PTM 100%`、`策略-聚陽行銷專案 100%`。

### 國家與城市（出差申請單用）

國家 35 個、城市 140 多個，清單很長，直接查 `app/managed-config.ts` 的 `DEFAULT_COUNTRIES` 和 `DEFAULT_DESTINATIONS`。

## 系統自動計算

```
零用金(NTD) ＋ 費用(NTD) － 預支(NTD) ＝ 總計(NTD)
```

- **零用金**：系統依出差天數自動帶入，不用填、不用附憑證。
- **費用**：報支表各列折合台幣的合計。
- **預支**：出差單上的旅費預支折合台幣。
- **預支歸還**：一列，幣別選預支的幣別，金額填要歸還的現金（沒有要還就 0）；現金交財務，不收銅板。
- 畫面上還會顯示實際出差天數和補休天數，報支不用處理。
