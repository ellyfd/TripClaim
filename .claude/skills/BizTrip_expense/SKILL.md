# 出差報支整包

把一趟出差的單據整理成可直接送件的一包。你是引導者：使用者多半不知道要交什麼、順序是什麼，**一次只要一樣東西**，每收一批就回報認到什麼、還缺什麼。

- 版面與金額規則：[`references/rules.md`](references/rules.md)（動手前讀完）
- 公司系統的欄位與下拉選單：[`references/system-fields.md`](references/system-fields.md)
- 產生器：[`scripts/build_pack.py`](scripts/build_pack.py)，輸入格式見 [`assets/manifest.example.json`](assets/manifest.example.json)

## 對話方式

- 用繁體中文，句子短。每一步只問一件事，不要一次列出全部要求。
- 每收到一批檔案，用一張小表回報：認到哪幾筆、金額、歸哪個項目；再說下一步要什麼。
- 看不出用途或對不上帳的，問本人，不猜、不編。收據品名和本人說法不同時照本人說的歸類，原品名留在 Remark。
- 金額、卡號、姓名都是個人資料：產出物放 session 暫存目錄，不 commit 進 repo。

## 步驟

### 1. 先拿出差的範圍

請使用者**貼出差申請單（截圖即可）**；沒有的話問出差日期區間和地點。

從出差單記下（欄位說明見 system-fields.md）：出差期間、城市、去回程班機、機票付款方式與金額、旅費預支（幣別／金額／匯率）、接送機。這些就是第 5 步核對缺漏的底稿。

### 2. 實體單據的照片

請使用者把**手上有紙本的**都拍照傳上來：登機證、紙本收據、刷卡單、紙本發票。一張照片可以拍多張單據。

逐張判讀：日期、商家、原幣金額、付款卡末四碼。分成三種，後面處理方式不同：

| 種類 | 例子 | manifest 的 `kind` |
|------|------|--------------------|
| 小張收據／刷卡單 | 熱感紙收據、刷卡簽單 | `small`（要印頁會留黏貼位） |
| A4 紙本 | 飯店發票 | `a4`（另附，不留位） |
| 登機證 | — | `boarding`（交實體，不印不留位） |

### 3. 電子檔

請使用者傳**本來就是電子檔**的憑證：訂房網站收據、Uber／外送電子收據、電子發票 PDF。

### 4. 信用卡明細截圖

列出第 2、3 步裡**所有外幣消費**，請使用者到信用卡 app 逐筆截圖：**台幣入帳金額**和**國外交易手續費**（有些銀行在同一張，有些分兩張）。

**幣別不在系統選單的消費**（例如波蘭幣，清單見 system-fields.md）一定要有信用卡明細，因為只能轉台幣報；沒有明細就無法報，要明講。

用原幣金額＋商家＋日期配對。對不上的不要硬配：那是另一筆消費，回頭跟使用者要它的收據，或確認不報。

### 5. 核對缺漏（一定要做，主動提醒）

對照出差單和已收到的單據，逐項檢查，把缺的列成清單給使用者：

- **機票**：去程、回程登機證各一張？出差單上的機票金額有了嗎？
- **住宿**：出差期間每一晚都有住宿憑證嗎？現場加收（城市稅、早入住）有沒有另一張發票？
- **每筆外幣消費**：原幣收據、台幣入帳、手續費三樣齊了嗎？缺入帳截圖的，問要補截圖還是直接報原幣。
- **幣別不在系統選單**的消費：信用卡明細有了嗎？
- **只有帳單沒有收據**的消費：要補收據，或確認不報。
- **只有刷卡單沒有品項**的：問買了什麼、要不要報。
- **常漏的**：機場接送、當地交通、網卡／漫遊、簽證、行李託運。出差單上有填但沒單據的，問一聲。
- **旅費預支**：出差單有預支的，報支表要加一列「預支歸還」。
- **費用歸屬**：請使用者提供（不代填）。

缺的補齊或使用者說「不補、就這樣」之後才往下。

### 6. 確認報支表

照 rules.md 第 1、2 節算金額與憑證數、決定怎麼分列（一列＝項目×幣別；被迫轉台幣的自己一列），把報支表（七欄）列給使用者確認。同項目多筆時編號：餐1、餐2、車1、車2。

### 7. 產出

1. 把所有檔案放進一個工作資料夾，寫 `manifest.json`（照範例）。
2. 執行：

   ```bash
   python3 scripts/build_pack.py <工作資料夾>/manifest.json
   ```

   需要 Pillow、pypdf、openpyxl 和一個中文字型。
3. **打開要印.pdf 的每一張截圖頁看過**：字清楚、沒被切、留位框和截圖列有對齊。腳本處理不了的版面（例如一個項目超過兩張小收據又很多截圖）自己調 manifest 或分項。
4. 交付 zip 和要印.pdf。每次改版換 `version`，不覆蓋舊版。

### 8. 告訴使用者怎麼送件

- 系統「旅費報支申請」照 Excel 一列一列填，附件選 `上傳/` 裡同名的檔。
- 要印.pdf 列印時選**實際大小**；小收據貼在虛線框，A4 紙本和登機證附在後面。
- 有預支歸還的，現金交財務。

## 產出物

```
要印.pdf            直接印
<出差名稱>.xlsx     項目｜幣別｜金額｜憑證數｜附件｜Remark｜費用歸屬
上傳/               1_機票(自行刷卡).pdf、2_住宿.pdf …（含實體單據照片）
```
