# 公司系統欄位

來源：出差申請單與旅費報支申請畫面的截圖。標「待補」的是還沒看過完整選單的欄位，遇到時請使用者截圖，補進這份文件。

## 出差申請單（用來核對，不用填）

| 欄位 | 用途 |
|------|------|
| 預計出差期間 | 核對住宿晚數、單據日期是否在範圍內 |
| 出差地點（洲別／國家／城市） | 檔名、判斷幣別 |
| 行程安排 | 哪幾天飛行、哪幾天工作 |
| 台北接送機 | 有填就要有接送的憑證，或確認由公司安排（不用報） |
| 班機／交通方式 | 去回程班次、艙等、時間 → 對登機證 |
| 旅費預支（需求日期／幣別／金額／匯率／折合台幣） | 有預支 → 報支表加「預支歸還」一列 |
| 機票付款方式 | 「自行刷卡」→ 報支項目用「機票(自行刷卡)」 |
| 人資作業：國際段機票／內陸段機票／改票費／簽證費／護照費／住宿 | 機票金額以這裡為準（例：同仁自購的金額） |

## 旅費報支申請（要填的七欄）

| 欄位 | 型態 | 內容 |
|------|------|------|
| 項目 | 下拉 | 見下表 |
| 幣別 | 下拉 | 見下表 |
| 金額 | 數字 | 有信用卡明細填台幣（含手續費），沒有填原幣 |
| 憑證數 | 數字 | 算法見 rules.md |
| 附件 | 上傳一個檔 | `上傳/` 裡對應的 PDF |
| Remark | 文字 | 金額組成 |
| 費用歸屬 | 選取 | 見下 |

### 費用歸屬（選取，待補）

格式是「歸屬名稱 ＋ 百分比」，例如 `<專案或部門名稱> 100%`，可分攤給多個歸屬。選項因人因專案而異，由本人提供。

## 系統自動計算

```
零用金(NTD) ＋ 費用(NTD) － 預支(NTD) ＝ 總計(NTD)
```

- **零用金**：系統依出差天數自動帶入，不用填、不用附憑證。
- **費用**：報支表各列折合台幣的合計。
- **預支**：出差單上的旅費預支折合台幣。
- **預支歸還**：一列，幣別選預支的幣別，金額填要歸還的現金（沒有要還就 0）；現金交財務，不收銅板。
- 畫面上還會顯示實際出差天數和補休天數，報支不用處理。
